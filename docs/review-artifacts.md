# Review Artifacts

All outputs generated by Vega Labs are strictly categorized as Review Artifacts.

## The `data/review` Directory
- Artifacts are saved to `houses/vega-lab/data/review/**`.
- This directory is in `.gitignore` to prevent generated data from accidentally mutating the main repository history.
- Only deterministic fixtures under `tests/fixtures/` should be committed.

## Common Schema Fields
Every generated Vega artifact conforms to a strict JSON schema ensuring it includes:
- `id`
- `type`
- `title`
- `summary`
- `source_refs`
- `evidence_refs`
- `derived_from`
- `generated_by`
- `created_at`
- `updated_at`
- `confidence`
- `limitations`
- `review_state`: MUST default to `pending`
- `visibility`: MUST default to `internal`
- `recommended_action`
- `target_outputs`
- `tags`

This ensures full provenance and prevents accidental publication of unreviewed AI outputs.
