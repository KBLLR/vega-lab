# Technology Alerts

Technology Alerts are generated by analyzing repo signals to detect emerging trends, vulnerabilities, or new tooling opportunities.

## Alert Types
- `dependency_update`: A critical update or new standard is identified.
- `new_library_opportunity`: A library could replace or enhance existing Core-X functionality.
- `security_or_maintenance_risk`: The repository indicates a security issue or deprecation.
- `model_release`: A new AI model repository is found.
- `framework_trend`: A shift in ecosystem standards is observed.
- `ecosystem_match`: A tool perfectly matches Core-X architecture patterns.
- `deprecation_warning`: An existing tool is being phased out.

## Output Structure
Generated as internal artifacts in `data/review/technology-alerts/<slug>.json`.
Must include:
- `severity`
- `relevance_to_corex`
- `affected_houses`
- `recommended_action`
- `evidence_refs`
- `review_state` (always `pending`)
- `visibility` (always `internal`)
