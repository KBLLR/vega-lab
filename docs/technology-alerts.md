# Technology Alerts

Technology alerts are draft-only Vega Labs recommendations about libraries, model families, runtime patterns, or infrastructure changes that may matter to Core-X.

## Alert Sources

- Starred repositories with high activity or adoption relevance.
- Owned repositories with repeated maintenance or deployment weak spots.
- Model-zoo candidates and downloaded model state.
- OCR/vision worker failures, missing capabilities, or incompatible request formats.
- External MLX/OpenAI-compatible server patterns worth adopting.

## Alert Rules

- Alerts must cite source repo/url or runtime evidence.
- Alerts must distinguish observation from recommendation.
- Alerts must include confidence and recommended action.
- Alerts do not mutate registries, create houses, publish docs, or open PRs automatically.

## Review States

- `pending`: generated and not reviewed.
- `reviewing`: being evaluated.
- `accepted`: approved for follow-up.
- `dismissed`: intentionally ignored.
- `published`: approved for public or ecosystem-facing output.
